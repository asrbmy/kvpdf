Privacy Policy

Last updated: August 2026

The short version: your PDF files never leave your device. There is no server that receives them, ever. Everything — rendering, editing, OCR, export — happens inside your own browser.

What KVPDF does with your files

KVPDF is a static web page. It has no backend, no database, and no file upload endpoint of any kind. When you open a PDF, it's read directly into your browser's memory using JavaScript libraries (pdf.js and pdf-lib) that run entirely client-side. The file is processed, rendered, and edited locally. When you export, the resulting PDF is generated in your browser and handed to you as a download — it is never transmitted anywhere.

This is true for every feature, including OCR (which runs via Tesseract.js, a WebAssembly OCR engine that also runs locally) and the compare/batch tools.

What is stored, and where

KVPDF autosaves your working session (page order, annotations, form field values, and the file itself) so that refreshing the tab doesn't lose your work. This is stored using your browser's local storage mechanisms — it stays on your device. Depending on how you're accessing KVPDF, this may be:

  • Standard browser storage, if you're using the app at its own URL — data stays in that browser profile, on that device, and is never sent to us or anyone else.
  • If you're using KVPDF inside an AI assistant's file-preview environment, that environment may provide its own storage layer scoped to your account there — subject to that platform's own privacy policy, not ours.

You can clear this at any time via the "Clear saved session" option in the app's document menu.

The "share / collaborate" feature

KVPDF includes an optional, off-by-default feature to sync annotations with collaborators via a session code. If you choose to use it, the annotations you draw (not the underlying PDF file) are written to a shared storage location, readable by anyone who has the code. Don't share a code for anything sensitive. This feature is opt-in — nothing is shared unless you explicitly click "Generate share code" or "Join."

Third-party network requests

KVPDF loads its core libraries (pdf.js, pdf-lib) and, only when you use those specific features, JSZip and Tesseract.js from cdnjs (Cloudflare's public CDN), and fonts from Google Fonts. These are standard library/font downloads — the same kind almost every website makes — and do not involve sending your PDF content. Cloudflare and Google may log the fact that a request for a given library/font file was made, per their own standard CDN operation, in the same way any CDN request works across the web; no data about your documents is included in these requests.

Analytics

This site does not currently run any analytics or tracking script. If that changes, this section will be updated first, and it will only ever be a privacy-respecting, cookie-free analytics tool (e.g. Plausible) that measures aggregate traffic — never anything that reads or reports on file contents.

Cookies

KVPDF does not set cookies.

Changes to this policy

If this policy changes, the "Last updated" date at the top will change accordingly. Given the project's single core promise — nothing is ever uploaded — any future change here is expected to be about storage/analytics details, not that promise itself.
