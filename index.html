KVPDF — Free Client-Side PDF Editor

KVPDF is a free, open-source PDF editor that runs entirely in your web browser — no file uploads, no server, no account required. Highlight and draw on PDFs, permanently redact sensitive text, insert images and hand-drawn signatures, fill out existing PDF forms or create your own fillable text fields and checkboxes, merge pages from multiple PDFs, reorder and rotate pages, extract page ranges, add watermarks and page numbers, and export as a new PDF. Everything happens client-side using pdf.js and pdf-lib, so your documents never leave your device.

Security

Adding a password isn't available here — the pdf-lib engine this tool runs on doesn't support PDF encryption. For a password-protected copy, try your OS's "Print to PDF" with a password, or a desktop tool like qpdf.

Opening a PDF that already has a password: KVPDF will prompt for it and can display/search the document, but editing and export aren't supported for encrypted source files (same pdf-lib limitation) — save an unprotected copy first if you need to edit it.

Share / collaborate

Best-effort sync: annotations are shared under a session code and merged every few seconds. Not real-time (no live cursors) — everyone needs to already have the same PDF open locally. Anyone with the code can read and write to that session.

EXPERIMENTAL. Syncs annotations live via a peer-to-peer connection (WebRTC) using Yjs — edits appear on collaborators' screens within a second or two instead of every few seconds, and merges are conflict-free by construction rather than last-write-wins. It relies on public WebRTC signaling infrastructure to help peers find each other, which can be blocked by strict firewalls/VPNs — if peers can't connect within about 15 seconds, this automatically falls back to Basic sync so you're never stuck.

Semantic search EXPERIMENTAL

Finds passages by meaning, not just exact words — e.g. searching "liability" can surface a sentence about "who's responsible for damages." Runs a small AI model entirely in your browser (via transformers.js) — nothing about your document is sent anywhere. The first time you use this, it downloads a ~25–90MB model, which your browser then caches for next time. Indexing a long document can take a couple of minutes on slower devices — this is genuinely running a neural network on your CPU, not a shortcut.

Find & redact by pattern

Scans every page for matching text and lets you review each hit before redacting. Works on both real text and any pages you've already run OCR on. Text-based matches use a proportional estimate of where a match sits within its line, so double-check the preview before applying — especially on unusual fonts or right-to-left text.
